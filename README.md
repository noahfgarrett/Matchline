# SSM Compiler

Drop in the five contract-standard project documents — MEL, cable schedule, Easy Power export, PMD, P6 schedule — and compile a complete Start-Up System Matrix: the SSM workbook, a backfilled MEL with provenance, the UPN predecessor matrix, and a QA/acceptance scorecard.

Standalone single-file app (`SSMCompiler.html`), zero runtime dependencies, built on a one-time fork of SSManagement's core modules (see `docs/FORK.md` once the fork lands).
